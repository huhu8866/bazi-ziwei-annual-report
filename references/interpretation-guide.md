# 解读方法论 —— 流年 / 大运 / 贵人断法

> 本文件是"怎么断"的干货，你改解读话术主要改这里。

## 〇、先分清「两套大运体系」（最易错）

脚本会分别输出两套**互相独立**的十年运，**不可混用、不可混称**：

| 体系 | 来源 | 起运 | 命名示例 | 记法 |
|---|---|---|---|---|
| **八字大运** | lunar-typescript `getYun`（子平法） | 出生后约 3 岁交运 | 丁酉 34–43 岁 | 以**干支**为主，论对日主的生克 |
| **紫微大限** | iztro `decadal`（紫微法） | 从命宫起，各宫十年 | 辛卯 34–43 岁（落子女宫） | 以**落宫**为主，论宫位吉凶 |

> 写报告时**必须注明**"以下为八字大运 / 紫微大限"。若两体系给的时间段不同，以各自体系为准，不要强行统一。

## 一、大运（十年一换）

1. **八字大运**：读脚本"八字大运"块，看 `◀ 当前所在` 标出的那一运。
   - **干支十神**：对照日主，判断此运是"帮身"还是"耗身"（如日弱喜印比，则印比运为吉）。
   - 换运节点常是人生转折（换工作、迁居、成家）。提示"交运前后一年内动作最活跃"。
2. **紫微大限**：读"紫微大限"块，看落宫：
   - 落官禄=事业年段；落财帛=财运段；落仆役/迁移=人际外出段；落田宅=家宅资产段。

## 二、流年（逐年）

`逐年流年表` 每行给四个钥匙：

| 字段 | 断法 |
|---|---|
| **流年命宫** | 落命宫=自身主角年（主动出击）；父母=长辈/上司/体制；福德=名望/才华/贵气；夫妻=合作/伴侣；财帛=进财年；官禄=事业爆发（叠加吉运则为高峰）；迁移=外出变动；田宅=房产家宅；疾厄=健康注意；仆役=朋友人际 |
| **天干十神** | 对照日主：印星年(正印/偏印)=得贵人/学习/靠山；比劫年=同辈合作但也破财；财星年=进财机会；官杀年=压力/责任/竞争；食伤年=才华外泄、耗身 |
| **地支五行** | 看是否补日主喜用。喜用年顺，忌神年滞 |
| **流年四化** | 禄=机会/轻松/进财落点；权=掌控/压力/权威落点；科=名声/文书/认可落点；忌=风险/破耗/是非落点。**重点关注"忌"落入哪个宫**，那就是当年要守的地方 |

### 叠加判高低
- 流年命宫 + 大运宫位 **双吉**（如同时落官禄、且干支帮身）→ 高峰年，果断发力。
- 流年忌 落 财帛 → 防钱财口舌；落 夫妻 → 防合伙反复；落 田宅 → 房产/家事要清爽；落 疾厄 → 重养生。

## 二·B、流月（按使用当日推算本年逐月）

脚本"本年逐月表"给 12 个节气月的：交节日、月干支、月干十神、月支五行对日主、月支十神。

**断法**：
1. **月干十神定"事件类型"**：印月=学习/靠山/文书；比劫月=合作但防破财；财月=进财机会；官杀月=压力/责任/竞争；食伤月=才华外泄、耗身。
2. **月支对日主的生克定"能量强弱"**：为喜用（如日弱见印比之地）→ 得力，宜进；为忌神 → 耗力，宜守。
3. **叠加流年**：若流年大方向为守，则流月的吉月也只宜"小步推进"，不宜逆势大动。
4. **操作模板**：
   - 吉月（月干为喜神 / 与流年用神同气）→ 安排签约、发布、面试、启动。
   - 凶月（月干为忌 / 月支冲克日支）→ 守成、回避重大决策、重健康与账目。

> 流月以**节气交接**为界，不是农历初一。给用户说明月份时要写清交节公历日期（脚本已给）。

## 三、贵人断法（重点）

贵人 = **本盘贵人星位** × **当年被激活的宫** 的交集。

### 本盘贵人星（先查"贵人星落宫"块）
| 星 | 象征 | 来路 |
|---|---|---|
| 天魁（阳贵） | 男性贵 | 常在 仆役/官禄 → 朋友圈、职场 |
| 天钺（阴贵） | 女性贵 | 常在 田宅/命宫 → 家宅、长辈 |
| 左辅·右弼 | 平辈搭档贵 | 常在 父母/命宫 → 一左一右成对出现 |
| 文昌·文曲 | 文贵 | 文书、才学、名声引路 |
| 天贵·天才 | 贵显/才华 | 福德/命宫 → 有声望、有真才的人 |
| 天德·月德 | 逢凶化吉 | 困局中恰好出现 |
| 禄存·天马 | 财贵/动贵 | 若同宫=禄马交驰，财动并旺 |

### 八字天乙贵人属相（快速对照）
| 年干/日干 | 天乙贵人生肖 |
|---|---|
| 甲、戊、庚 | 丑(牛)、未(羊) |
| 乙、己 | 子(鼠)、申(猴) |
| 丙、丁 | 亥(猪)、酉(鸡) |
| 壬、癸 | 卯(兔)、巳(蛇) |
| 辛 | 午(马)、寅(虎) |

### 相遇场景推断
- 流年**禄/权飞入迁移** → 外出、出差、远行中遇贵。
- 流年**科飞入父母** → 长辈、女性文职、机构引路。
- 流年**科飞入仆役** → 朋友、同事、社群引荐。
- 流年命宫入**福德** → 自身贵气外显，被才俊赏识。

### 贵人画像通用维度
属相（按上表）× 五行（对照喜用）× 性别（阳贵=男/阴贵=女）× 年龄（父母宫=年长、仆役=平辈）× 行业（对应其五行）。

## 三·B、近5年建议的写法

脚本"近5年逐年表"给每年：流年命宫、年干十神、年支五行对日主、流年四化落宫。

**写法**：
1. 先给**一句话节奏**（如"2 年守、2 年顺、1 年收"），把 5 年串成叙事。
2. 每年写三点：**主题**（命宫落点）→ **机会**（禄/权落宫）→ **风险**（忌落宫）+ 一条操作。
3. 结尾给**跨年红线**（如"忌担保、房产留痕"），让人记住最重要的一条。

## 四、喜用神判法

- 先看日主强弱（得令/得地/得势三要素），弱则喜生扶（印、比劫），强则喜克泄耗（财、官、食伤）。
- 再看调候（寒暖燥湿），如夏生火旺急取水润。
- **若不同工具结论冲突**：选更细致的子平法，且在报告里明确写"本报告采信 X 派结论"，不要把矛盾结论并列抛出。

## 五、合规红线（不可越）

- 不预测具体死亡时间、寿命、重大疾病诊断。
- 不替代投资/法律/医疗/婚姻决策。
- 婚姻合婚只作性格与相处参考，不作"是否该结婚"的裁定。
- 每份报告结尾必须带免责声明。

## ★ 报告固定风格标准（陈老师 2026-10-05 拍板，所有人一律照此）

生成任何人的解读时，**必须**满足以下五条，这是硬性模板，不是建议：

| 维度 | 标准 |
|---|---|
| **详细度** | 必须拆到「每年 · 发生什么 / 为什么 / 怎么做」三层，不能只给结论 |
| **语言** | **全大白话**。术语出现时，紧跟一句人话解释（例：「身弱」→「你本命能量偏薄，扛不住太多消耗」） |
| **指导性** | 每年必须给**可执行动作**：该主动出击 / 该守成 / 该避开什么，要具体到做法 |
| **年龄口径** | 🔴 **全文统一用周岁**。大运表可加一列虚岁对照，但正文一律周岁，并显式标注「本报告全文年龄均按周岁」。**严禁周岁虚岁混用**（曾因此出现"2029年44岁"错误） |
| **结构顺序** | ① 一句话总结 → ② 你是什么料（日主/格局/天赋）→ ③ 保命符（喜用神：颜色/方位/行业/作息）→ ④ 人生节奏（大运表，含周岁+虚岁双列）→ ⑤ 逐年拆解 → ⑥ 财富级别 → ⑦ 感情 → ⑧ 事业 → ⑨ 健康 → ⑩ 操作手册（一张表把上面变成"今天能做的事"） |

### 逐条落地示例（照抄语气与颗粒度）

- ❌ 不合格：「戊戌运较好，事业有成。」
- ✅ 合格：「**43 周岁（2029年）进入戊戌运，这是你中年唯一的黄金十年**——土生金、帮身最强。为什么好：你身弱怕消耗，这十年恰好补你的底。怎么做：2029–2031 别急着扩张，先把 2026–2028 欠的债收干净；2032 之后再上杠杆。注意：戌未相刑，这运虽好但带官非摩擦，合同、合作、报税务必留痕。」

### 收尾强制项

报告末尾必须固定加上免责声明：
